# Novi Express projekat

Jednostavan Node.js projekat napravljen pomoću Express-a.

## Pokretanje

```bash
npm install
npm run dev
```

Aplikacija je dostupna na `http://localhost:3000`.

- `GET /` vraća pozdravnu poruku.
- `GET /health` vraća status servera.

Za standardno pokretanje koristi `npm start`. Port možeš promeniti preko promenljive okruženja `PORT`.
